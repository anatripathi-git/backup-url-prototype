Reviewer checklist

  • Current blade fidelity: existing policy command, scheduled-backup message, database search, Earliest restore point (UTC), and Restore action remain recognizable.
  • Shared setup: confirm that both policy and Back up now use consistent destination selection, managed identity, SQL credential, network, and storage-access validation.
  • Entry point: confirm that the current database resource clearly determines scope for Back up now without a scope or database selector.
  • Right pane: confirm one continuous pane is preferable to a three-tab wizard for this focused operation.
  • Destination: review Local as the default and explicit Azure Blob storage selection.
  • Preflight: review eligibility, identity, network, and Blob role remediation.
  • Operation model: confirm that the prototype acknowledges request submission without promising a customer-visible monitoring surface.
  • Accessibility: verify keyboard focus, close behavior, status announcements, reduced motion, and responsive layout.
